# Changelog

## 0.2.0

- Job > Search: new **Sort** option, newest postings first by default (uses the API's `sort` parameter).
- Techmap Trigger: requests the newest postings first, so new jobs are found on the first page.
- Fix: **Exclude Duplicates** now sends the `isDuplicate` parameter the API expects (it had no effect before).

## 0.1.1

- Use the supported node category "Marketing & Content".

## 0.1.0

- Initial release: Techmap node (Job > Search, Job > Get RSS Feed URL), Techmap Trigger (New Jobs) and Techmap API credential.
